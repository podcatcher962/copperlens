【这是什么】

  一块板子摆在手上，只想知道"这根线通到哪儿、两头是哪颗元件的哪只脚"。
  这个程序就是干这个的：打开板子文件，点一下走线或焊盘，整条铜亮起来，
  状态栏直接写出 U100-4 / C102-1 这样的具体脚位。

  只读 —— 绝不修改、覆盖、删除你的任何原始文件。


【怎么打开】

  1) 双击 PCB看板.exe
  2) 点左上角"打开文件"
  3) 选 .pcb 板文件，或 .ddb 设计库
     —— 两种文件在同一个对话框里，不用切换按钮

  也可以：把文件直接拖到 exe 图标上；或者拖进程序窗口里。
  一个 .ddb 里常常有好几块板，打开后顶栏会出现下拉框，
  按修改日期从新到旧排，最新那块标 ★。


【查线怎么看】

  · 点一下走线或焊盘 → 与它电气相连的整片铜亮黄，其余变暗
  · 状态栏写出脚位，例如：
        GND    U100-4 / C102-1 / C103-1 +7
    意思是这条线从 U100 的 4 脚出发，一共连到 10 只脚。
    你点中的那只脚永远排在最前面。
  · 鼠标停在焊盘上不动，光标旁会浮出 "U100-3  10uF/10V"
  · 点大面积接地/电源平面时，只点亮接在它上面的元件脚，
    铜皮本身只描轮廓 —— 不然整板一片黄，什么也看不出来
  · 按 Esc 或点空白处取消高亮


【看图】

  滚轮            缩放（以鼠标指着的位置为中心，指哪儿放哪儿）
  按住左键拖      平移
  ▲ ◀ ◎ ▶ ▼      画布右下角的方向按钮，◎ 回到板子中心
  键盘方向键      平移（按住 Shift 走得快）
  +  -            缩放
  0               回到中心
  F               适合窗口
  H               一键隐藏／显示全部铺铜（看细走线最好用）
  左栏点层名      开关该层
  左栏双击层名    只看这一层


【标注】

  位号（U3 / R12）、焊盘号（1 / 2 / 3…）默认都开，顶栏可关。
  元件型号在左栏"视图 → 显示型号 / 值"。
  标注会互相避让：缩小时只留位号，放大后焊盘号才一个个出现。

【打不开 / 显示不对怎么办】

  · 提示"文件里没有找到 PCB 数据段"
        → 这个文件不是 PCB 4.0 二进制格式。
          .ddb 里如果只有原理图或元件库，是没有 PCB 可看的。
  · 提示"跨页存储，直接读会错位"
        → 设计库里的这块板被切成了碎片存，硬读会画出一张假图。
          程序宁可明说不能看，也不给假图（照着假图查线是会出事的）。
          处理：先在原来的软件里把它导出/另存成本机的 .pcb 文件，
                再把那个 .pcb 拖进来。
  · 完全没反应
        → 看运行记录：%TEMP%\CopperLens\last-run.log
          把这个文件发过来就能定位。


【运行环境】

  · Windows 7 / 8 / 8.1 / 10 / 11，32 位和 64 位系统都能跑
    （程序本身是 32 位，64 位系统向下兼容，不用另装 32 位系统）
  · 已在 Windows 10（32 位）和 Windows 11（64 位）上实测通过
  · 显示要靠系统里的 Edge 或 Chrome：
    Win10 / Win11 自带 Edge，不用另装；
    Win7 / Win8 没带，需要自备一个
  · 不联网、不写注册表、不装任何运行库、不需要 Python
  · 文件大小约 8.5 MB，拷到 U 盘就能带走
