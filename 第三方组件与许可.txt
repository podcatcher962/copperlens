1. mdbtools —— 读 .ddb 设计库
────────────────────────────────────────────────────────────────
用 途：.ddb 设计库的本质是 Microsoft Jet / Access 数据库。本程序
        调用其中的 mdb-export.exe 把表导出成 CSV，再自行解析。

版 本：mdbtools v1.0.0（MSYS2 / MinGW 的 Windows 32 位构建）

许可协议（同一项目里两部分许可不同，请注意区分）：
  · 命令行工具（mdb-export.exe 等）        —— GNU GPL v2.0 或更新
  · 库 libmdb / libmdbsql / libmdbodbc     —— GNU LGPL
  GPL-2.0 全文见同目录 COPYING-GPL-2.0.txt
  LGPL 全文见       同目录 COPYING-LGPL-2.1.txt

上游项目（源码与许可证原文以这里为准）：
    https://github.com/mdbtools/mdbtools

随程序一同分发的文件：
    mdb-export.exe          GPL-2.0-or-later
    libmdb-3.dll            LGPL（动态链接调用，未做修改）
    libiconv-2.dll          LGPL（GNU libiconv）
    libgcc_s_dw2-1.dll      GPL-2.0 附 GCC Runtime Library Exception
